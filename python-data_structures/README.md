# python-data_structures

This is a project for the Higher Level Programming track. It covers the basics
of Python data structures — lists, tuples, and how to work with them without
relying on built-in shortcuts.

## About

Each file is a standalone script with one function in it, following the
naming convention `N-function_name.py` where N is the task number.

## Requirements

- Ubuntu 20.04 LTS, python3 (3.8.5)
- pycodestyle 2.7
- Every file starts with `#!/usr/bin/python3` and ends with a new line
- All files are executable

## Files

- `0-print_list_integer.py` - prints each integer in a list on its own line
- `1-element_at.py` - gets an element from a list by index, safely
- `2-replace_in_list.py` - replaces an item in a list at a given index
- `3-print_reversed_list_integer.py` - same as task 0 but reversed
- `4-new_in_list.py` - like task 2 but doesn't touch the original list
- `5-no_c.py` - strips c/C out of a string
- `6-print_matrix_integer.py` - prints a matrix, one row per line
- `7-add_tuple.py` - adds two tuples together
- `8-multiple_returns.py` - returns length + first char of a string
- `9-max_integer.py` - finds the max value in a list, no max()
- `10-divisible_by_2.py` - returns True/False for each item depending on evenness
- `11-delete_at.py` - deletes an item from a list at an index
- `12-switch.py` - swaps two variables in 5 lines
